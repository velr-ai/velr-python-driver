velr_client

Synchronous, dependency-free Python client for openCypher-compliant Velr Server.

Use VelrClient as a context manager to own a connection. Query methods return ClientResult; collect or discard its remaining rows before issuing another command on that connection. RemoteDatabase names a database on a shared client. Connections and their results must be used serially.

Query parameters and result cells use JSON-compatible Python values. Client and server failures raise VelrClientError; opening a connection may also raise standard socket or TLS exceptions. A lost ordinary write response has an unknown outcome. Use run_idempotent from the first attempt when retrying a supported replicated write.

error.report retains the original diagnostic without its remote code prefix; error.explanation supplies the concise explanation when available. Optional error.position is an ErrorPosition with named line and column fields and ordinary tuple indexing, unpacking, and equality.

The velr_client.guide and velr_client.query_language modules expose complete usage and query-language references through installed-package help and generated documentation.

class ErrorPosition ( typing.NamedTuple ) :

An immutable source position in the complete submitted query.

line is the one-based source line and column is the one-based Unicode display-cell column, matching the rendered diagnostic. Wide and combining characters can differ from editor character, UTF-16, or byte offsets.

Construct with ErrorPosition(line, column). Instances support named access, tuple indexing, unpacking, and equality with ordinary (line, column) tuples. Values are copied metadata and survive connection and result closure. Errors use None when the server cannot identify a single source position.

class VelrClientError ( builtins.Exception ) :

Base exception for client, transport, protocol, and server failures.

Catch this exception around both query execution and result consumption. Errors can arrive from run(), pull(), or collect(). Subclasses and category/detail support programmatic handling without inspecting the diagnostic wording. All metadata is copied and survives connection closure.

Attributes: code: Original machine-readable server/client code, or None. Query failures use velr.error. Stops use query.cancelled and query.deadline_exceeded. query.outcome_unknown and client.connection_lost mean a command's outcome is unknown. message: Original error text without the code prefix. str(error) preserves this text and includes the code when present. report: Alias for the original message, without the code prefix. explanation: Structured human-readable explanation, or message when the server does not supply one. Its wording may change. category: Stable classified category, or None. New categories may be added by newer servers. detail: Stable category-specific reason, or None. Applications must allow unknown detail values. phase: "compile" or "runtime" for classified Cypher failures, otherwise None. Fetch timing does not determine the phase. hint: Optional human-readable remediation text. position: Optional ErrorPosition in the complete query, with one-based line and Unicode display-cell column fields. It remains compatible with (line, column) tuples. Unknown or ambiguous positions are None. retryable: Whether a classified condition may be transient. It does not guarantee that replaying a write or transaction is safe. Unknown outcomes are always False; use the explicit idempotent-write API from the first attempt when retrying supported replicated writes. status_code: Always None: the server protocol does not expose a local C ABI call status. sqlite_errorcode: Optional SQLite extended numeric result code. sqlite_errorname: Optional SQLite symbolic result-code name. io_kind: Optional portable server filesystem error kind, such as "not_found" or "permission_denied". os_code: Original error number from the server's platform, or None. It is not interpreted as an error number on the client's platform. operation: Optional failed filesystem operation on the server. path: Optional database path associated with the server failure.

Servers without structured diagnostics retain ordinary VelrClientError failures and existing code values. Stops still have typed exceptions; other categories are not inferred from diagnostic text. Initial socket/TLS connection setup can raise standard socket or TLS exceptions.

VelrClientError( message: str, *, code: str | None = None, category: str | None = None, detail: str | None = None, phase: str | None = None, explanation: str | None = None, hint: str | None = None, position: ErrorPosition | tuple[int, int] | None = None, retryable: bool = False, sqlite_errorcode: int | None = None, sqlite_errorname: str | None = None, io_kind: str | None = None, os_code: int | None = None, operation: str | None = None, path: str | None = None)

Create an error from its original message and optional code.

These preserve the existing diagnostic and string representation. Other keyword arguments initialize the same-named attributes documented on the class; explanation defaults to message. Metadata defaults to None or False. Subclasses supply a category when it is omitted. A position tuple becomes an ErrorPosition; passing an existing ErrorPosition preserves that instance.

class CancellationToken:

Request cancellation of server queries from any thread.

Pass this token as cancellation to VelrClient.run() or RemoteDatabase.run(). It can stop every query using it, including while results are fetched. A cancelled token stays cancelled. Create a fresh token for independent work. Keep client and result handles on the query's thread.

def cancel(self) -> None:

Request cancellation of active queries and return None.

The query or row fetch reports the outcome. If a request cannot be delivered, this method raises VelrClientError with code client.cancel_failed.

class VelrClient:

One synchronous Velr Server session, initially using database default.

Use connect or connect_tls for a direct node connection, or connect_cluster / connect_seeds for reconnection across gateways. with client: closes the socket on exit, including exceptional exits. Call close() explicitly when managing its lifetime yourself; repeated calls are safe.

Only one result or transaction may be active on a connection. Finish a result with collect() or discard() before another command. Use separate clients for concurrent tasks; database handles share this session.

VelrClient(sock: socket.socket)

Adopt a socket without performing a handshake or authentication.

This low-level constructor owns and closes sock. Application code should use a connect* factory to establish a ready server session.

@classmethod
def connect( cls, host: str = '127.0.0.1', port: int = 7777, *, timeout: float | None = None, token: str | None = None):

Open a direct plaintext connection and optionally authenticate.

host and port default to 127.0.0.1:7777. timeout is the socket timeout in seconds; None disables the timeout. token is an optional bearer token. This connection does not recover or replay commands automatically. Use TLS for protected networks.

Returns a client owned by the caller. Socket connection errors may be raised as OSError; handshake/authentication failures may raise VelrClientError. Failed setup closes the socket.

@classmethod
def connect_seeds( cls, seed_endpoints: Iterable[tuple[str, int]], *, timeout: float | None = None, token: str | None = None, reconnect_rounds: int = 3, initial_reconnect_backoff: float = 0.05, max_reconnect_backoff: float = 1.0, gateway_refresh_interval: float = 30.0):

Open a reconnecting plaintext session from (host, port) seeds.

At least one seed must be reachable. token authenticates the session. timeout is a socket timeout in seconds; None disables the timeout. Successful discovery supplies fallback gateways. Prefer connect_cluster with TLS and stable DNS for production.

Reconnection tries reconnect_rounds rounds (default 3), with jittered exponential delays from initial_reconnect_backoff (0.05 seconds) up to max_reconnect_backoff (1.0 second). Gateway discovery refreshes on commands after gateway_refresh_interval (30 seconds). Timeouts, rounds, intervals and the initial backoff must be positive; the maximum backoff must be at least the initial backoff. The client keeps at most 64 configured and discovered endpoints.

Ordinary interrupted commands are not replayed. Authentication and the selected database are restored when reconnecting succeeds; active results and transactions are not restored.

@classmethod
def connect_cluster( cls, host: str, port: int = 7777, *, timeout: float = 5.0, token: str | None = None, ca_file: str | None = None, server_hostname: str | None = None, context: ssl.SSLContext | None = None, reconnect_rounds: int = 3, initial_reconnect_backoff: float = 0.05, max_reconnect_backoff: float = 1.0, gateway_refresh_interval: float = 30.0):

Open a reconnecting session through a logical hostname and port.

timeout defaults to 5 seconds and applies to socket operations. token supplies the bearer identity. Supplying ca_file, server_hostname or context enables TLS; otherwise this factory uses plaintext. ca_file names a trusted PEM CA file and server_hostname defaults to host for certificate verification. Pass either context or ca_file, never both. A supplied SSL context must be configured for verified native TLS; see connect_tls.

The hostname is resolved again on reconnection. The client restores authentication and the selected database, then uses discovered gateways as fallbacks. Reconnection timing, limits and validation are the same as connect_seeds. Ordinary interrupted commands are not replayed; run_idempotent has one bounded automatic retry before rows start.

@classmethod
def connect_tls( cls, host: str, port: int = 7777, *, ca_file: str | None = None, server_hostname: str | None = None, timeout: float | None = None, token: str | None = None, context: ssl.SSLContext | None = None):

Open a direct TLS connection and optionally authenticate with token.

ca_file names a PEM CA file; omit it to use system trust roots. server_hostname defaults to host and controls hostname checking. timeout is a socket timeout in seconds; None disables it. The default context verifies certificates and hostnames, requires TLS 1.3, and advertises ALPN velr-native/1.

Supply either ca_file or a preconfigured ssl.SSLContext through context. A supplied context is used unchanged: configure certificate verification, TLS versions and the required ALPN yourself. Failure to negotiate velr-native/1 raises VelrClientError. TLS/socket setup can raise standard ssl.SSLError / OSError exceptions. A direct connection does not recover or replay commands automatically.

def close(self) -> None:

Close the owned socket; repeated calls have no effect.

Finish results and commit or roll back transactions before closing. Closing does not report whether an interrupted write committed.

def run( self, cypher: str, *, params: dict[str, Any] | None = None, max_rows: int | None = None, consistency: str = 'leader', causal_token: dict[str, Any] | None = None, timeout: float | None = None, cancellation: CancellationToken | None = None) -> ClientResult:

Execute Cypher on the selected database and return a pending result.

params maps parameter names (without $) to JSON-compatible values: None, booleans, signed 64-bit integers, finite floats, strings, lists and string-keyed dictionaries. max_rows is an optional server result-row limit, independent of result pull batches.

consistency is leader by default; stale, local, read_your_writes and linearizable are also accepted by the server. causal_token is a database-scoped token dictionary with database_id and nonnegative integer applied_index. A read-your-writes request uses this client's remembered token when none is supplied. Returned tokens advance client.causal_token.

timeout is a finite, nonnegative number of seconds. Its single deadline covers execution and all result pulls. None leaves it unset and 0 expires immediately. Invalid values raise ValueError. Pass a CancellationToken as cancellation to request a stop, including from another thread. The query or result raises VelrClientError with code query.cancelled or query.deadline_exceeded when stopped. If Velr cannot confirm the outcome of a stopped replicated write, it raises query.outcome_unknown.

Collect or discard the result before another command. VelrClientError may be raised while starting or pulling rows. An ordinary command is never replayed after a lost connection; a write may already have committed.

def run_idempotent( self, cypher: str, operation_id: str, *, params: dict[str, Any] | None = None, max_rows: int | None = None, consistency: str = 'leader', causal_token: dict[str, Any] | None = None) -> ClientResult:

Execute a retry-safe autocommit write on a Raft-managed database.

operation_id is an application-chosen, nonempty string of at most 256 UTF-8 bytes, scoped to the selected database. Keep it and the Cypher, parameters and result limit identical on every retry. Remaining options match run. Reads and explicit transactions are rejected. Stored results are limited to 16 MiB and retained for the database lifetime.

A reconnecting cluster client retries once automatically if a transport loss occurs before the result starts. Direct connections do not. A loss while pulling rows must be handled by calling this method again with the original inputs; the stored result restarts at its first row. Inspect ClientResult.operation_id and replayed for the response. Persist the operation id and inputs before the first attempt when retries must survive an application restart.

def authenticate(self, token: str) -> None:

Authenticate with a nonempty bearer token.

A cluster client retains the token in memory to authenticate recovered connections. It is never saved to disk by this package.

causal_token: dict[str, Any] | None

Return a copy of the latest token for the selected database, or None.

A token has database_id: str and applied_index: int. Older responses cannot move the remembered position backward. Explicitly routing a database clears the token, including routing to the same name.

def discard(self) -> None:

Discard the current session result's unread rows.

Prefer ClientResult.discard() so that result also records completion. Discarding rows does not undo mutations or roll back a transaction.

def begin(self) -> int:

Begin an explicit transaction and return its integer id.

Explicit transactions are supported on RF=1 databases. Subsequent run calls on this session use the transaction until commit or rollback. Finish any active result before starting a transaction.

def commit(self, tx: int) -> None:

Commit the active transaction identified by begin()'s tx.

Finish its last result first. A lost response leaves commit outcome unknown; a transaction is not restored by reconnecting.

def rollback(self, tx: int) -> None:

Roll back the active transaction identified by begin()'s tx.

def route_database(self, name: str) -> None:

Select an existing named database and clear the remembered causal token.

Finish active results and transactions before changing databases. Successful selection is restored on a cluster reconnection.

def route_default_database(self) -> None:

Select database default and clear the remembered causal token.

def status(self) -> dict[str, typing.Any]:

Return server status for this session as a dictionary.

Core fields include server_version, protocol_version, uptime_ms, scheduling_policy, metrics and native_connections. Optional sections depend on server features. Use database_status(name) for a named database's lifecycle record.

def create_database( self, name: str, *, request_id: str | None = None) -> dict[str, typing.Any]:

Create name and return its database lifecycle record.

The server chooses replicas using its default replication factor. An omitted request_id generates a UUID; retain and reuse an explicit id with the same name for retries across connections or process failure. Creating a database does not select it. Authorization is server-enforced.

def list_databases(self) -> list[dict[str, typing.Any]]:

List database lifecycle records visible to the authenticated identity.

def database_status(self, name: str) -> dict[str, typing.Any]:

Return name's lifecycle record without changing database selection.

Records include database_id, replication_factor, lifecycle, replicas and leader_preference. Optional fields include owner, creation_request_id, operation_id and failure.

def database(self, name: str) -> RemoteDatabase:

Select name and return a handle that shares this connection.

A handle reselects its database before a query or begin when needed. Handles do not own sockets and cannot be used concurrently on one client.

def cluster_status(self) -> dict[str, typing.Any]:

Return cluster policy, nodes and database/operation counts.

The dictionary includes policy, nodes, database_count, ready_database_count and pending_operation_count. Administrative operations require the corresponding server permissions.

def list_nodes(self) -> list[dict[str, typing.Any]]:

Return node records, each containing node and observed counts.

Records also contain hosted_replica_count, preferred_leader_count and observed_liveness (unknown/local/reachable/unreachable).

def join_node( self, node: dict[str, typing.Any], *, request_id: str | None = None) -> dict[str, typing.Any]:

Register a node with lifecycle joining and return its node record.

node requires integer node_id and max_active_database_groups. Optional fields are native_address / raft_address strings, max_storage_bytes and string-to-string labels. This method forces the joining lifecycle. request_id defaults to a generated UUID; reuse a stable id and identical inputs when retrying an administrative change.

def update_node( self, node: dict[str, typing.Any], *, request_id: str | None = None) -> dict[str, typing.Any]:

Replace a node's registration with node and return its node record.

Fields match join_node; lifecycle may also be supplied. This accepts a complete registration, not a partial patch. Reuse a stable request_id and unchanged inputs to retry; omitted ids are generated.

def activate_node( self, node_id: int, *, request_id: str | None = None) -> dict[str, typing.Any]:

Set node_id active for new replicas; return its node record.

request_id has the same retry semantics as set_node_lifecycle.

def drain_node( self, node_id: int, *, request_id: str | None = None) -> dict[str, typing.Any]:

Mark node_id draining; return its node record.

Monitor progress before removing the node. request_id has the same retry semantics as set_node_lifecycle.

def declare_node_lost( self, node_id: int, *, request_id: str | None = None) -> dict[str, typing.Any]:

Declare node_id lost for repair planning; return its node record.

request_id has the same retry semantics as set_node_lifecycle.

def set_node_lifecycle( self, node_id: int, lifecycle: str, *, request_id: str | None = None) -> dict[str, typing.Any]:

Change a node lifecycle and return its node record.

lifecycle is a server-validated string: joining, active, draining, lost or removed. Use remove_node for removal. Reuse a stable request_id and identical inputs on retry; omitted ids are generated UUIDs. Completion does not imply repair work has finished.

def remove_node( self, node_id: int, *, request_id: str | None = None) -> dict[str, typing.Any]:

Remove an eligible node and return its node record.

A placement-control voter cannot be removed until its control membership is changed separately. request_id is generated when omitted; retain a stable id with identical inputs when retrying.

def set_cluster_policy( self, policy: dict[str, typing.Any], *, request_id: str | None = None) -> dict[str, typing.Any]:

Replace cluster policy and return the accepted policy dictionary.

Required field: default_replication_factor. Optional fields: failure_domain_label (a node-label key or None), max_concurrent_rebalances and max_concurrent_rebalances_per_node (both default 1). This is a complete policy, not a partial patch. request_id defaults to a UUID; reuse a stable id and identical inputs when retrying. Existing database RFs are changed separately.

def rebalance_cluster(self, *, request_id: str | None = None) -> dict[str, typing.Any]:

Request a rebalance decision, returning a dictionary with state.

States are stable, planned (with plan), or deferred (with code and message). A planned decision is not a completion report. request_id defaults to a UUID; reuse it with unchanged inputs on retry.

def alter_database_replication_factor( self, name: str, replication_factor: int, *, request_id: str | None = None) -> dict[str, typing.Any]:

def pull(self, limit: int) -> list[list[typing.Any]]:

Fetch up to limit remaining rows; use a positive batch size.

Returns an empty list after exhaustion. Pulling consumes rows, so later pulls or collect return only the remainder. Remote execution errors or connection loss raise VelrClientError here, after run has returned. The query's deadline and cancellation token remain active during each pull. Either stop error marks the result finished.

def collect(self) -> list[list[typing.Any]]:

Fetch all remaining rows in batches of 1024 into a Python list.

This allocates memory for the remaining result. Call pull instead when processing a large result incrementally. Query or connection failures raise VelrClientError while fetching rows.

def discard(self) -> None:

Discard unread rows and mark this result finished; safe to repeat.

This does not undo a write or roll back a transaction. Call while its client is still open and this remains the active result.
