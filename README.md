# Velr Python drivers

Use Velr as an embedded graph database or connect to a Velr server from Python.
Both packages require Python 3.12 or later.

Install the embedded driver:

```sh
pip install velr
```

- [Installation and quick start](https://velr-ai.github.io/velr-python-driver/velr/getting_started.html)
- [Driver guide](https://velr-ai.github.io/velr-python-driver/velr/guide.html)
- [API reference](https://velr-ai.github.io/velr-python-driver/velr/driver.html)
- [Query language reference](https://velr-ai.github.io/velr-python-driver/velr/query_language.html)
